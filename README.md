# USRSE26 poster: Developing RSE skills at the novice level

Poster for US-RSE '26 (San Jose). Reception Monday Oct 19, 2026. Camera-ready Wednesday Oct 21. Max size 44 x 44 in. The PDF also goes to Zenodo.

Built with Quarto + Typst. Coauthors edit words in plain text and open a pull request. Start a new branch for each change: a push to a branch whose pull request has already merged does not reach `main`.

## Edit the words

Everything on the poster is in `poster.qmd`.

- Change the words freely. Keep the `:::` lines: they place each block on the page.
- `# Heading` is a panel title. `## Heading` is a sub-heading inside a panel.
- `::: {.carleton}` and `::: {.ucla}` wrap an example and tag it with its school.
- `::: {.cells columns="1fr 2fr"}` with `::: {.cell}` inside makes independent areas; text stays in its own area.
- Title, authors, and footer are in the block at the top of the file.
- Chart numbers are in `data/outcomes.csv` (`category,count`). The chart redraws itself.
- `<!-- TODO ... -->` comments mark open questions.

### Writing rules

Short sentences, one idea each. One name per thing: *DataSquad* (program and team), *students*, *researchers*, *staff*. Say what students do and what staff give, not metaphors. No em dashes. Claims need a source: a project write-up, a citation file or DOI, or a number someone can check.

Do not edit `typst-template.typ` or `areas.lua` unless you are changing the layout.

## Build

Needs [Quarto](https://quarto.org) 1.9 or later (it bundles Typst).

```bash
quarto render poster.qmd     # writes poster.pdf
```

The Atkinson Hyperlegible font (OFL license) is in `fonts/` and loads automatically.

Two Typst packages download on the first render, so you need an internet connection: `fletcher` (the flow diagram) and `wrap-it` (text that wraps around the helicopter photo). Their versions are pinned at the top of `typst-template.typ`.

## What CI does

`.github/workflows/render.yml` renders the poster on every push and pull request, then checks that `poster.pdf` is exactly one page, 3168 x 3168 pt (44 x 44 in), with every font embedded. A red check usually means text overflowed onto a second page: shorten the text in the tallest column.

After a merge to `main`, CI commits the new `poster.pdf` and `poster.typ` back (message `Render poster [skip ci]`). Pull before you edit locally. Do not edit those two files by hand. If one conflicts in a pull request, keep the copy from `main`.

## Before it goes to print or Zenodo

0. Set `poster-draft: false` at the top of `poster.qmd` to remove the DRAFT watermark, then re-render.
1. Check `pdfinfo poster.pdf`: one page, 3168 x 3168 pt (44 x 44 in).
2. Look at the whole page and zoom into every section for overflow.
3. Scan the QR code on a phone.
4. The logo and watermark are vector traces of the 215 px DataSquad International PNG (`assets/data-squad-int.png`). Ask Paula for the original vector file and swap it in if one exists; the trace is good but not the source.
5. Print a small paper proof.
6. Zenodo: follow `submission/zenodo-deposit.md` (upload the PDF only, reserve the DOI, keep the record as a draft until the final PDF is ready).

## Layout

| File | Purpose |
|---|---|
| `poster.qmd` | Words and settings |
| `typst-template.typ`, `typst-show.typ`, `areas.lua` | Layout, colors, header, flow diagram, roles, example graphics, outcomes chart |
| `poster.pdf`, `poster.typ` | Generated by CI. Do not edit by hand |
| `data/outcomes.csv` | Alumni outcome counts (aggregates only) |
| `data/README.md`, `scripts/` | Data dictionary and the script that builds the local alumni dataset |
| `design/` | Prompts used for outside design and content review |
| `submission/` | Title, abstract, presenters, keywords for EasyChair |
| `assets/`, `fonts/` | Logo, QR code, font, helicopter photo |

Alumni names, emails, and positions are never committed. Only category counts are. Everything else in `data/` is git-ignored.

The four icons in `assets/pathways-*.svg` (laptop with gears, steps, open book) were traced to vector from an AI-generated drawing (made with Gemini Notebook; its watermark was cropped out and is not in the repo). The Venn diagram and all labels are live text and shapes in `typst-template.typ`. `assets/carleton-scraper-improvements.svg` is a vector comparison of the election-news scraper before and after the students' changes, generated outside the repo (text is outlined, so it is not editable text; regenerate it to change the wording). Its content comes from the Carleton ITS blog post "Election News Analysis project" (3 June 2024), which is credited under it on the poster. The four role icons in `assets/role-*.svg` were traced the same way from the DataSquad roles drawing; the role names and descriptions are live text in `typst-template.typ` (`role-cards`).

The helicopter photo in `assets/` is by Chris Yarzab, [CC BY 2.0](https://creativecommons.org/licenses/by/2.0/), from [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:LAPD_AS350B2-2.jpg). It was cropped and resized. Keep its credit line on the poster.

Style follows datasquad.info: navy `#1D3557`, steel `#457B9D`, orange `#F9AE1A`, Atkinson Hyperlegible.
